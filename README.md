A make.fun bounty entry for "Fridge Roast: One Line, Biggest Laugh": one line, at most 200 characters, roasting a smart fridge. The program writes the line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). The program is fully deterministic: every run writes the same bytes to `/output/entry.txt`, and it reads the file back to verify the output is byte-identical before exiting.

## Entry line (147 characters)

> My smart fridge updated its firmware and now the ice maker needs a login, the door needs Wi-Fi, and the milk needs a software license to stay cold.
